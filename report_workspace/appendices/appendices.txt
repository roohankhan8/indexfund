Appendix C: Variable Definitions and Formulas

This appendix should formally define the main variables used in the final KSE-30 workflow.

C.1 Main Target Variable

Fund flow:

flow_t = AUM_t - AUM_(t-1) * (NAV_t / NAV_(t-1))

Interpretation:
This formula isolates investor subscriptions and redemptions by removing the portion of AUM change that is explained only by NAV movement.

C.2 Monthly NAV Return

nav_return_m = NAV_end / NAV_start - 1

Interpretation:
This is the monthly percentage change in fund NAV within each month.

C.3 Aggregate Sector Flow

total_fund_flow = flow_AKD + flow_NBP + flow_NTI

Interpretation:
This is the main final target variable in `6_cursor_model/`, treated as the aggregate KSE-30 sector flow.

C.4 Flow Normalization

flow_pct_sector = total_fund_flow / sector_aum_prev

Interpretation:
This expresses sector flow relative to the size of the sector in the previous month.

C.5 Reconstructed KSE-30 Index Return

idx_log_return_t = ln(idx_ff_mcap_total_t / idx_ff_mcap_total_(t-1))

Interpretation:
This is the daily log return of the reconstructed KSE-30 index built from constituent free-float market capitalization totals.

C.6 Rolling Volatility

rolling_vol_30d = std(log_returns over past 30 days) * sqrt(252)

Interpretation:
This annualizes 30-day rolling volatility using the standard 252-trading-day convention.

C.7 Selected Forecasting Variables

1. `interest_rate_end`: end-of-month policy rate
2. `cpi_yoy_end`: end-of-month CPI year-on-year inflation
3. `oil_return_monthly`: summed monthly oil log return
4. `usdpkr_return_monthly`: summed monthly exchange-rate log return
5. `idx_return_monthly`: monthly reconstructed KSE-30 return
6. `idx_vol_monthly`: month-end 30-day rolling KSE-30 volatility

C.8 Rebalancing Variables

1. `cur_weight`: current constituent weight before the next review
2. `mom_30`, `mom_60`, `mom_90`: rolling momentum signals
3. `vol_30`, `vol_60`: rolling volatility measures
4. `avg_volume`: average trading volume
5. `mkt_cap_proxy`: market-cap proxy used in the rebalancing panel
6. `price_to_ma20`, `price_to_ma50`: price relative to moving averages
7. `wt_drift`: change in weight from its earlier level
8. `wt_range`: historical range of observed weight
