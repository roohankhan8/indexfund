Appendix C: Variable Definitions and Formulas

C.1 Fund flow identity
`flow_t = AUM_t - AUM_(t-1) * (NAV_t / NAV_(t-1))`

C.2 Monthly NAV return
`nav_return_m = NAV_end / NAV_start - 1`

C.3 Aggregate sector flow
`total_fund_flow = flow_AKD + flow_NBP + flow_NTI`

C.4 Flow normalization
`flow_pct_sector = total_fund_flow / sector_aum_prev`

C.5 Reconstructed KSE-30 index return
`idx_log_return_t = ln(idx_ff_mcap_total_t / idx_ff_mcap_total_(t-1))`

C.6 Rolling volatility
`rolling_vol_30d = std(log_returns over past 30 days) * sqrt(252)`
